# 咕噜 · 品牌形象规范（v0.2）

完整设计稿（含表情、姿态、标识、样机、生图提示词）：https://claude.ai/artifact/J7guTq6LUoNQAuvGqZwHk3

## 一句话
咕噜是咕噜漫画的看店猫：一只白色英国短毛猫，黑色在尾巴和后腿上，脖子上挂一枚金色吊牌。名字来自猫打呼噜的声音“咕噜咕噜”。

## 品牌调性
- 界面整体精致克制（黑金 / 高级灰 / 米白三套主题），可爱元素只留在咕噜身上。
- 咕噜性格：安静、慢热、靠谱、一点点傲娇、爱书。不做大表情，情绪靠眼睛开合和尾巴。
- 它不说话。文案用旁白口吻（如“咕噜先替你占个位”），不用“喵～”之类卖萌台词。
- 同一屏最多出现一只咕噜；不放在按钮、卡片、导航图标本身，不遮挡作品内容。

## 外形
| 部位 | 规范 |
|---|---|
| 被毛 | 纯白（偏暖白 #FAF8F3） |
| 尾巴 | 整条纯黑 #1C1A18，粗、尾尖圆钝，长约坐高 0.8 |
| 后腿黑斑 | 臀部到后腿外侧左右各一块，严格对称，同尾巴黑；正面只在身体两侧露一道边，背面最完整 |
| 头 | 大而圆，宽:高 ≈ 1.3:1，双颊饱满（英短“包子脸”），下巴短 |
| 耳 | 小、圆钝、间距宽、外倾约 20°，耳内灰玫 |
| 眼 | 大圆眼，琥珀金 #D9A441，竖瞳；默认半眯 |
| 口鼻 | 小鼻灰玫 #D7A79C，ω 嘴，每侧两根淡胡须 |
| 身体 | 坐姿约 1.6 头身，敦实、腿短、脚掌圆 |
| 吊牌 | 唯一配饰。深黄褐细绳 #8B5A2B 绕颈，大半藏在双颊下；胸前圆角方形金属金吊牌 #D6B06A（亮 #F3DC9A / 暗 #A97A26），约一只眼大小，刻小“咕”字；全身唯一有金属光泽处 |
| 线条 | 暖墨描边 #2A2622（不用纯黑），平涂，最多一层浅阴影 #E9E4DA |
| 不做 | 衣服、铃铛、其他配饰、其他花色、头部或前腿出现黑色 |

## 标识
- **主标**：端坐全身像，尾巴从身后绕到前脚，两侧露后腿黑斑，胸前吊牌。`svg/logo-mark.svg`
- **组合标**：主标 + 字标“咕噜漫画”（宋体系衬线、字距放宽），横版用于顶栏/侧栏，竖版用于启动页；英文副标 GULU COMICS，字距 0.32em。
- **App 图标 / 网站大图标**：探头构图，咕噜扒着图标底边看你，黑尾在右侧竖起、尾尖回勾。三套主题：`svg/app-icon-blackgold.svg`（尾巴描金边）、`app-icon-gray.svg`、`app-icon-ivory.svg`。
- **小尺寸（≤32px，favicon、顶栏小图）**：只留头，去掉胡须和嘴，眼睛为两点。`svg/logo-head-small.svg`；单色版 `svg/logo-head-mono.svg`（可改 stroke/fill 为任一主题色）。
- 48px 以上用主标，32px 以下用小头像。

## 表情与姿态（用途）
- 表情：淡定（默认）、好奇（搜索/发现）、咕噜（被点、读完一话）、吃惊（更新提醒）、开心（签到/成就）、无语（断网/出错）。`svg/face-*.svg`
- 姿态：端坐（品牌/关于）、香箱趴书（空书架/更新）、团睡（夜间/离线）、探头（无结果/下拉刷新）、背影（“我的”、下一话预告）。`svg/pose-*.svg`
- 辅助图形“尾巴符号”：加载时一截尾巴绕圈；选中态下方一道带勾短尾；章节结束分隔符。

## 与漫画《失声招领处》的关系
漫画里的“咕噜”是一团没有五官的声骸，与品牌猫是两个角色，各管一边：猫负责 App/官网外壳（Logo、空状态、加载等），漫画内容与角色介绍继续使用光团咕噜。官网介绍作品时不要把两者画成同一个角色。
