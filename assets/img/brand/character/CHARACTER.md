# 咕噜 · 人形角色设定（v0.1）

原型：频道头像里的毛毡剪纸猫 `../channel-avatar.png`（白色英短坐姿、黄绿眼、粉耳内、黑色卷尾、后腿黑斑、棕色项圈挂金色圆吊牌）。
这是“咕噜”的人形二次元版本，用于后续产品宣传、视频、周边。猫形规范见 `../BRAND.md`，本文件只管人形。

## 一句话
咕噜漫画书店的看店姑娘：白发猫耳、黑色卷尾、黑色过膝袜，脖子上一条棕色皮项圈挂着刻有“咕噜”二字的金色小吊牌。安静、慢热、爱书，一点点傲娇。

## 设定基本面
| 项 | 设定 |
|---|---|
| 名字 | 咕噜（Gulu） |
| 外观年龄 | 成年少女感，约 19 岁；身材纤细、不夸张 |

| 场景 | 书店柜台后、书架间、窗边看书 |

## 从猫到人的特征映射（必须全部保留，这是辨识度）
| 猫原型 | 人形落地 |
|---|---|
| 纯白被毛 | 暖白发色，头部和手臂上不出现任何黑色 |
| 大圆眼、黄绿色 | 大圆眼，虹膜橄榄黄绿，竖椭圆瞳孔（猫瞳感，但不要锐利），上眼睑默认微微下垂（半眯、淡定） |
| 立起的白猫耳、粉色耳内 | 头顶一对白色猫耳，耳内珊瑚粉，耳内有几缕白色绒毛；与人耳二选一：**不画人耳**，鬓发盖住耳朵位置 |
| ω 嘴、粉鼻 | 小嘴，默认嘴角呈很浅的 ω 形；脸颊淡珊瑚粉腮红 |
| 胡须 | 不画胡须。用脸颊两侧各三缕细长的鬓发呼应 |
| 黑色粗尾、尾尖卷成圈 | 一条粗而蓬松的纯黑猫尾，从裙后伸出，尾尖向内卷成一个圆钝的勾（像头像里那样卷），不要细长鞭状尾 |
| 后腿对称黑斑 | 黑色过膝袜（两腿严格对称），袜口在膝盖上方约一掌处，袜口有一圈细细的白色绒边 |
| 前爪白、圆 | 手部白皙；开衫袖口宽松、盖到指根，有“猫爪袖”的感觉 |
| 棕色项圈 + 金色吊牌 | 棕色皮革细项圈（choker，宽约 1.5cm），正前方用小金环挂一枚金色圆形吊牌（直径约 3cm，带一圈细凸边），牌面压印两个汉字“咕噜”（横排、圆体字形，笔画粗细均匀、端点圆润，深金色凹刻），这是她最重要的标志物 |

## 发型
- 暖白色中长发，长度到锁骨下方；发尾蓬松、微微外翘，有毛茸茸的质感。
- 齐刘海偏碎，刘海正中留一小撮翘起的呆毛。
- 脸颊两侧各三缕细长鬓发垂到下巴下方（呼应胡须）。
- 发色阴影偏暖米灰，高光偏奶油色，不要冷蓝白、不要银灰。

## 服装（书店日常装，定稿版）
- **上衣**：奶油白圆领衬衫，领口系一条细细的青绿色（同头像背景色）短领结。
- **外套**：宽松的燕麦米色粗针织开衫，长度到臀部，前襟敞开，两个口袋；袖子偏长盖住半个手掌。开衫袖口和下摆各一圈暖棕色细边。
- **下装**：青绿色百褶短裙，裙长到大腿中部偏下（不走光、不性感化）。
- **腿**：黑色过膝袜（见上）。
- **鞋**：深棕色圆头玛丽珍鞋，一字扣带，扣是小金扣。
- **配饰**：只有项圈吊牌 + 一枚金色书签形发夹（夹在左侧刘海上）。不加铃铛、蝴蝶结发饰、眼镜、耳环。
- **道具**（立绘可选）：双手抱一本厚的棕色精装书，书脊有金色烫线。

## 画风
- 日系二次元赛璐璐上色，干净线稿，线色用暖墨 #2A2622 而非纯黑，阴影 1～2 层，柔和高光。
- 整体温暖、安静、书卷气，调性与“精致克制”的品牌一致。
- 不要：厚涂写实、过度光效、性感化姿势/服装、Q 版比例混入立绘。

## 默认表情与姿态
- 默认表情“淡定”：眼睛半眯约 2/3，嘴角极浅 ω，眉毛平。
- 默认站姿：正面直立，双手在胸前抱书，猫耳立起，尾巴从身后绕到身体右侧（画面左侧看是她的右边），尾尖卷勾。

## 表情（6 种，对应品牌猫）
| 名称 | 用途 | 画法 |
|---|---|---|
| 淡定 | 默认 | 半眯眼，嘴角浅 ω，耳朵立 |
| 好奇 | 搜索 / 发现 | 眼睛睁圆，头微歪，一只耳朵转向侧面 |
| 咕噜 | 满足、读完一话 | 眼睛弯成两道弧线，脸颊腮红加深，嘴角上扬 |
| 吃惊 | 更新提醒 | 眼睛睁大、瞳孔缩小，耳朵竖直，嘴小 o 形 |
| 开心 | 签到 / 成就 | 闭眼笑，嘴张开露一点点，耳朵微向前 |
| 无语 | 断网 / 出错 | 死鱼眼（上眼睑压到一半，瞳孔变小点），嘴一条直线，耳朵向两侧耷拉成飞机耳 |
